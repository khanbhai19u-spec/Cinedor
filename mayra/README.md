# MAYRA — Your Personal AI Assistant 🤖

বাংলা ও ইংরেজিতে কথা বলা পার্সোনাল AI অ্যাসিস্ট্যান্ট (Android)। মাথা হিসেবে চলে **Claude** (Anthropic)।

## ফিচার

| ফিচার | কীভাবে কাজ করে |
|---|---|
| 💬 AI Chat (বাংলা + English) | বাংলা, Banglish বা English যেভাবে লিখবেন সেভাবেই উত্তর দেবে, আর উত্তর লাইভ স্ট্রিম হবে |
| 🎤 Voice Chat | 🎤 চাপুন আর কথা বলুন (বাংলা/English বদলাতে ইনপুট বক্সের **বাং/EN** চাপুন) |
| 🔊 Voice Response | ভয়েসে প্রশ্ন করলে উত্তর পড়ে শোনাবে, বাংলা লেখা হলে বাংলা ভয়েসে। চাইলে **হ্যান্ডস-ফ্রি** মোড চালু করুন |
| 👏 Clap Activation | সেটিংসে চালু করুন, তারপর দুইবার হাততালি দিলে MAYRA খুলে বলবে "জি, বলুন?" |
| 🖼️ Image Understanding | 📎 → গ্যালারি/ক্যামেরা থেকে ছবি দিয়ে প্রশ্ন করুন |
| 📄 PDF ও Document Analysis | PDF, DOCX, TXT, CSV, কোড ফাইল দিন, সারাংশ বা বিশ্লেষণ পাবেন |
| 🌐 Web Research | খবর, দাম, আবহাওয়া এসব নিজে থেকেই ইন্টারনেটে খুঁজবে, সাথে সূত্রও দেবে |
| 🧠 Personal Memory | "মনে রাখো আমার জন্মদিন ১২ মার্চ" বললে মনে রাখবে। 🧠 বাটনে সব দেখা ও মোছা যায় |
| 💻 Coding Assistant | হেডারের **</>** চাপলে কোডিং মোড চালু হয়। কোড ব্লকে **কপি** বাটন আছে |

## ১. APK বানানো (GitHub Actions)

`mayra/` ফোল্ডারে কিছু বদলালে আর push করলে **Build MAYRA** workflow নিজে থেকেই APK বানায়।
- **Actions → Build MAYRA → সর্বশেষ run → Artifacts** থেকে `MAYRA-v…apk` নামান।
- রিলিজ বানাতে **Actions → Build MAYRA → Run workflow** চাপুন, version দিন (যেমন `1.0.0`)। APK তখন **Releases**-এ চলে আসবে।
- Cinedor-এর মতো একই `KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` secret দিয়ে সাইন হয়, তাই পরের আপডেট সরাসরি ইনস্টল হবে।

## ২. প্রথমবার চালু করা

1. APK ইনস্টল করে খুলুন।
2. **Claude API key** লাগবে:
   - [console.anthropic.com](https://console.anthropic.com) এ অ্যাকাউন্ট খুলুন
   - **Billing**-এ কিছু ক্রেডিট যোগ করুন (৫ ডলারেই অনেক দিন চলে)
   - **API Keys → Create Key** চেপে key কপি করুন
   - MAYRA → ⚙ সেটিংস → key পেস্ট করে **সেভ করুন**
3. সেটিংসে **সব অনুমতি দিন** চাপুন (মাইক, কন্টাক্ট, কল, নোটিফিকেশন)।
4. হাততালির জন্য: **হাততালি শোনা চালু** করুন, আর **"স্ক্রিন বন্ধ/অন্য অ্যাপে থাকলেও খুলতে অনুমতি দিন"** চেপে MAYRA-কে অনুমতি দিন।
5. বাংলা ভয়েসে শুনতে: ফোনের Settings → Text-to-speech → Google → বাংলা ভয়েস ডাউনলোড করুন।

### মডেল আর খরচ
সেটিংসে মডেল বাছাই করা যায়:
- **Opus 5.5**: সবচেয়ে স্মার্ট (ডিফল্ট)
- **Sonnet 5.5**: দ্রুত, খরচ প্রায় অর্ধেক
- **Haiku 5.5**: সবচেয়ে সস্তা ও দ্রুত, রোজকার ছোট কাজের জন্য ভালো

খরচ সরাসরি আপনার Anthropic অ্যাকাউন্ট থেকে কাটে। ছবি, PDF আর ওয়েব সার্চে টোকেন বেশি লাগে।

## সীমাবদ্ধতা (Android-এর নিয়ম)
- সাধারণ অ্যাপ নিজে থেকে Wi-Fi/Bluetooth/Mobile data অন-অফ করতে পারে না। MAYRA তাই সেই সেটিংস স্ক্রিন খুলে দেয়।
- SMS/WhatsApp মেসেজ লিখে রেডি করে দেয়, কিন্তু **Send** আপনাকেই চাপতে হবে। ভুল করে কাউকে মেসেজ চলে যাওয়ার ভয় এতে থাকে না।
- অন্য অ্যাপের ভেতরের লেখা পড়া বা সেখানে বাটন চাপা (যেমন Facebook-এ পোস্ট করা) এই ভার্সনে নেই।
- ফোন রিস্টার্ট হলে হাততালি শোনা চালু করতে একবার MAYRA খুলতে হয়। Android 14 বুটের সময় মাইক্রোফোন সার্ভিস চালু হতে দেয় না।
- ভয়েস রিকগনিশনের জন্য Google অ্যাপ আর ইন্টারনেট লাগে।

## কোড কোথায় কী
| ফাইল | কাজ |
|---|---|
| `MainActivity` | চ্যাট স্ক্রিন, ভয়েস, অ্যাটাচমেন্ট |
| `MayraAgent` | Claude API (স্ট্রিমিং, টুল লুপ, ওয়েব সার্চ, মেমরি প্রম্পট) |

| `ClapService` + `ClapDetector` | ব্যাকগ্রাউন্ডে হাততালি শোনা |
| `VoiceInput` / `Speaker` | Speech-to-text / Text-to-speech |
| `Attachment` | ছবি, PDF, DOCX, টেক্সট থেকে Claude content block বানানো |
| `MemoryStore` / `ChatStore` | মেমরি ও চ্যাট ফোনেই সেভ থাকে |
| `SettingsActivity` / `MemoryActivity` | সেটিংস ও মেমরি স্ক্রিন |
